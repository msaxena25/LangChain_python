# Models

The two main concepts are Discriminative Models and Generative Models. Both are used in Machine Learning, including Deep Learning.

## Discriminative Model

Purpose: Learns to distinguish between categories or predict an output from input data.

Example: You provide a cat or dog image, and the model predicts whether it is a cat or a dog.

- Input: Image
- Output: `Cat` or `Dog`

It learns the relationship.

## Generative Model

Purpose: Learns patterns in data and `can generate new` samples that resemble the learned data.

Example: You ask an image-generation model to create a picture of a cat, and it generates a new image.

- Input: Prompt or other conditioning information
- Output: Newly generated image

## Real-world examples

| Task                            | Model type               |
| ------------------------------- | ------------------------ |
| Detect spam vs. genuine email   | Discriminative           |
| Predict house prices            | Typically discriminative |
| Classify an image as cat or dog | Discriminative           |
| Generate a new image            | Generative               |
| Generate text using ChatGPT     | Generative               |
| Generate new music              | Generative               |

# What is Artificial Intelligence (AI)?

Artificial Intelligence, or AI, is a `branch of computer science` that focuses on building systems capable of performing tasks that typically require human intelligence, such as learning, reasoning, problem-solving, understanding language, recognizing patterns, and making decisions.

AI is a broad field that includes several approaches:

1. Machine Learning (ML)  
2. Deep Learning (DL)  
3. Generative AI  
4. Large Language Models (LLMs) 

### Example: An AI-powered enterprise chatbot uses - 

- LLM: Understands the user's question and generates a response.
- RAG: Retrieves relevant information from private company documents.
- Embeddings and vector search: Help find semantically relevant document chunks.
- Prompt engineering: Provides instructions and context to guide the model's response.
- Evaluation and guardrails: Help assess answer quality and manage risks.

## Machine Learning vs Deep Learning

**Machine Learning (ML)** is when a computer learns from data to make predictions or recognize things.

*Example:* A spam filter that learns to tell spam emails from non-spam by studying lots of emails.

**Deep Learning (DL)** is a special type of machine learning that uses brain-like structures called "neural networks" with many layers to learn from lots of data.

*Example:* `Face recognition` on your phone uses deep learning to recognize who you are from your photo.

**In short:**
- All deep learning is machine learning, but not all machine learning is deep learning.
- Deep learning works well with huge amounts of data—like pictures, speech, or videos.

# What are Tokens?

A token is a unit of text processed by an LLM. It can represent a word, part of a word, punctuation, or other text.

### Sizes - 

```
1 token ≈ 4 characters in English text.
1,000 tokens ≈ 750 words in typical English prose.

But that will be different in other language or code.
```

### Important points about Tokens

- Tokens are not exactly words or characters. A word can be one token or multiple tokens.
- Punctuation, spaces, numbers, code, and uncommon words affect token counts.
- Different models and `tokenizers` may split the same text differently.

# Context Window

The context window is the `maximum number of tokens` a model can process within its supported context for a request, including relevant input and generated output.

**Note** - A tokenizer affects how much text becomes tokens, but the context window is a separate model-design and deployment specification.

# Diff b/w Vector and Embedding

`A vector `is a list of numerical values, whereas an embedding is a vector that represents the meaning or features of data.

```
vector = [0.2, 0.5, 0.8, 0.1]
```

Vector is a general mathematical concept used in mathematics, physics, computer graphics, geography, AI, and many other fields.

**Example** - RGB colors [255, 0, 0] and latitude-longitude coordinates [28.6139, 77.2090] can be represented as vectors.

`An embedding` is a numerical representation of data, such as text, an image, or audio, generated by an embedding model. In a real application, an embedding may contain hundreds or thousands of dimensions.

```
embedding = [0.21, 0.75, -0.32, 0.48]
```

**Every embedding is a vector.** But **Not every vector is an embedding.**

# Coshine similarity 

Cosine similarity measures how similar the direction of two vectors is. In AI and RAG, it is commonly used to compare embeddings and find semantically similar text.

Range = −1 to 1.

Let's see one example.

### Step 1: Calculate cosine similarity

We have two vectors:

- A = [1, 2]
- B = [2, 1]

The formula for cosine similarity between two vectors **A** and **B** is:

cosine_similarity = `(A · B) / (||A|| × ||B||)`

Where:
- `A · B` is the dot product of vectors A and B.
- `||A||` and `||B||` are the `magnitudes` (lengths) of vectors A and B respectively.

1. **Dot product:**

> A · B = (1 × 2) + (2 × 1) = 2 + 2 = 4

2. **Magnitude of A:**

> ||A|| = sqrt(1² + 2²) = sqrt(1 + 4) = sqrt(5) ≈ 2.2361

3. **Magnitude of B:**

> ||B|| = sqrt(2² + 1²) = sqrt(4 + 1) = sqrt(5) ≈ 2.2361

4. **Cosine similarity:**

> cosine_similarity = 4 / (2.2361 × 2.2361) = 4 / 5 = 0.8

**Final result:**  
**Cosine similarity = 0.8**

cosine similarity ranges from −1 to +1. In our example, 0.8 indicates that the two vectors point in a similar direction.

| Cosine similarity | Meaning                                             |
| ----------------- | --------------------------------------------------- |
| `+1.0`            | Same direction — maximum directional similarity     |
| `+0.8`            | Strong directional similarity                       |
| `0.0`             | Perpendicular directions — no directional alignment |
| `−0.8`            | Opposite-ish directions                             |
| `−1.0`            | Opposite directions                                 |

## Calculate Angle

The angle is mainly a way `for us to understand cosine similarity geometrically`. In most RAG systems, AI applications use the cosine similarity score directly, not the angle in degrees.

IF we plot that vectors A and B on graph then angle between those is approximately 36.87 degreee.

- **Angle = 0°** means **Cosine similarity = +1.0** (same direction; maximum similarity)
- **Angle = 90°** means **Cosine similarity = 0.0** (perpendicular; no similarity)
- **Angle = 180°** means **Cosine similarity = -1.0** (exactly opposite directions; complete dissimilarity)

**Note:**  
- In LLM and RAG applications if similarity ≥ 0.7 or an angle less than ~45°, that is mostly considered.

# What is Attention mechanism?

**Sentense** - "The animal did not cross the street because `it` was too tired."

**The question is**: when the LLM processes the word "it", how does it determine that "it" refers to "the animal" rather than "the street"?

1. The model first converts the text into tokens and then into numerical representations called embeddings.
2. The model processes these token representations through its `Transformer layers` to build `context-aware representations`.
3. The Transformer allows each token's representation to add information from other relevant tokens in the context. And that is called `self-attention`.

For the token `it`, here's the simplified process:

- "animal" — an animal can become tired.
- "street" — a street generally cannot become tired.
- "because" — signals a reason for not crossing.

4. The model learns linguistic patterns and relationships from its training data. These patterns help it associate "it" with "the animal" as the most useful interpretation.

# Causal masking

Causal masking ensures that an LLM can only attend to the current token and previous tokens, not future tokens, when predicting the next token.

--------

# Feed-Forward

Feed-forward in a Transformer is the step right after self-attention. Attention lets a word look at the other words. Feed-forward then takes that one word’s updated meaning and rewrites it on its own, without looking at the other words again.

Flow:

Self-Attention → Feed-Forward Network → Next Transformer layer

Example: In the sentence "The animal is tired", 

- self-attention helps a token gather context from other tokens. 
- The feed-forward network then transforms that token's contextual representation to learn more complex features such as "state of the animal = exhausted.

# Types of Training

## Machine Learning Training

The three main types of Machine Learning training are:

1\. **Supervised Learning** — Trains on labeled data (input + correct answer).

- Example: Emails labeled as spam or not spam.

2\. **Unsupervised Learning** — Trains on unlabeled data to discover patterns or groups.

- Example: Grouping customers based on purchasing behavior.

3\. **Reinforcement Learning** — Learns through rewards and penalties for actions.

- Example: An AI agent learning to play a game.

## LLM Tranining

- **Pretraining**: This is self-supervised learning on a huge text corpus (web pages, books, code).

-  **Supervised fine-tuning (instruction tuning)**: The model is then trained with ordinary supervised learning (like instructions, optional input and desired answer) to produce that answer.

- **Preference alignment**: Supervised fine-tuning teaches one good answer. Alignment teaches the model which of several answers people prefer.

    - **RLHF** (reinforcement learning from human feedback) - This is most useful method of Preference Alignment.
    People rank answers. A reward model learns those rankings. The LLM is then updated with reinforcement learning (often PPO) to get higher reward.

# Context Window

When an LLM reaches its context window limit, it cannot process more tokens than its configured limit in a single request.

The application may then:

1. Reject the request because it exceeds the limit.
2. Remove or truncate older conversation history to make room.
3. Summarize older messages and send the summary instead.
4. Limit the generated response to keep the request within the available context.

## Context management strategies

1. Sliding Window — Keep only the most recent messages that fit within the context limit. Older messages are dropped as new messages arrive.

2. Conversation Summarization — Summarize older conversation messages into a compact summary. Send the summary plus recent messages to preserve important context.

3. Conversation Buffer / Memory — Maintain conversation history across requests and selectively include it in future prompts. The history may be stored in application memory or a database.

4. Structured State Management — Store important facts, preferences, task status, and decisions in structured fields rather than relying only on raw conversation history. Common in AI agents and multi-step workflows.

# How does an LLM choose the next token?

Suppose your prompt is: `The sky is`

The model might assign these probabilities to the next token:

| Candidate token | Probability |
| --------------- | ----------- |
| blue            | 60%         |
| clear           | 30%         |
| beautiful       | 12%         |
| falling         | 5%          |
| other tokens    | 3%          |

These are illustrative probabilities, not actual model outputs.

The model uses these probabilities to select a next token, depending on its decoding settings

### What is Top-k?

Top-k limits token selection to the k most probable candidates.

For example, if `top_k = 3`, the candidates are:

- blue — 60%
- clear — 30%
- beautiful — 12%

The remaining candidates are excluded from selection at that step.

### What is Top-p (nucleus sampling)?

Top-p selects the `smallest group of highest-probability` tokens whose cumulative probability reaches a specified threshold.

`Cumulative probability` is calculated by adding the probabilities one by one, starting with the highest-probability token.

Suppose `top_p = 0.80` or `80%`:

- blue — 60% (cumulative 60%)
- clear — 30% (cumulative 60 + 30 = 90%)

The candidate group would be `blue` and `clear` in this example.

The important point is that top-p requires the cumulative probability to reach or exceed 80%, not stay below 80%. Once threashold meets,stop there. And thats why group will be blue and clear.

# How to get Token Uses?

## 1. OpenAI / ChatGPT model — Python

Before sending the request: use the `OpenAI token-counting API` to count the input tokens.

```py
from openai import OpenAI

client = OpenAI()

result = client.responses.input_tokens.count(
    model="YOUR_MODEL_NAME",
    input="Explain cosine similarity."
)
print(result.input_tokens)
```

After receiving the response: check the `usage information` returned by the API.

```py
response = client.responses.create(
    model="YOUR_MODEL_NAME",
    input="Explain cosine similarity."
)

print(response.usage.input_tokens)
print(response.usage.output_tokens)
```

## 2. Gemini model — Python

Before sending the request:

```py
from google import genai

client = genai.Client()

result = client.models.count_tokens(
```

# Transformer : The architecture behind modern LLMs

A Transformer is a `deep-learning architecture` designed to process sequences of data, such as text, by using `attention mechanisms` to understand relationships between tokens.

## 1. Why do we need a Transformer?

Suppose we give an LLM this sentence:

> The animal did not cross the street because it was tired.

To understand this sentence, the model needs to determine what `it` most likely refers to. It needs to consider other words and their relationships, rather than interpreting every word independently.

Transformers help the model do this through self-attention, which allows each token to gather relevant information from other tokens.

## 2. How does a Transformer work?

```
Input text
    ↓
Tokenization
    ↓
Embeddings + position
    ↓
Transformer block  ←──────────────┐
    ↓                              │ next block (transformer block repeats many times..)
Self-attention                     │
    ↓                              │
Feed-forward                       │
    ↓                              │
Residual connections + normalization
    ↓                              │
    └──────────────────────────────┘
    ↓
Output layer (next-token scores)
    ↓
Token selection (top-p sampling)
```

## History of the Transformer

**2017 — Transformer introduced**

Eight researchers published a paper called `Attention Is All You Need`. Their main idea was a new model design called the Transformer. It reads a sequence of words using `attention`: each word looks at the other words and learns which ones matter.

Older models read text one word at a time, or in small local chunks. The Transformer can work on many words at the same time, so training is faster. Its first strong result was machine translation, turning text from one language into another.

**2020 onward — Large language models**

Very large Transformer models, such as GPT-3 and later ChatGPT, made this kind of language model widely used. Other companies built their own model families too, including Google's Gemini and Anthropic's Claude.
